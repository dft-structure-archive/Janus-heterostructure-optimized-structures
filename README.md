# Optimized Atomic Structures of Janus-Based Heterostructures

## 1. Overview

This repository provides the optimized atomic structures of the heterostructures investigated in the manuscript entitled "Electric Field Alignment Governs Interfacial Reconstruction and Photocatalytic Performance in Janus Z-scheme Heterojunctions".

All structures were obtained through first-principles calculations using the VASP package.

## 2. Repository Contents

The repository contains eight optimized atomic structure files in total:

| Heterostructure | Interfacial configurations | Number of structures |
|---|---|---|
| PtS₂/SiC | Optimized structure | 1 |
| PtSe₂/SiC | Optimized structure | 1 |
| PtSSe/SiC | S-side and Se-side interfaces | 2 |
| WSSe/HfS₂ | S-side and Se-side interfaces | 2 |
| WSSe/ZrS₂ | S-side and Se-side interfaces | 2 |

## 3. File Format

All structural files are provided in standard VASP POSCAR format, including lattice vectors, atomic species, atom counts, and atomic coordinates.

The files are organized into folders according to their corresponding heterostructures and interfacial configurations.

## 4. Data Scope

This repository provides optimized atomic structures only. Complete VASP input sets, raw computational output files, and additional electronic-structure calculation data are not included.

The computational methodology and relevant results are described in the associated manuscript and its Supporting Information.
