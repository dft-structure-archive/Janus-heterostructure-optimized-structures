# Optimized Atomic Structures, Representative VASP Input Files, and Selected Computational Data for Janus-Based Heterostructures

## 1. Overview

This repository provides the optimized atomic structures, representative VASP input files, and selected numerical data for the heterostructures investigated in the manuscript entitled "Electric Field Alignment Governs Interfacial Reconstruction and Photocatalytic Performance in Janus Z-scheme Heterojunctions".

All structures and calculations were obtained through first-principles calculations using the VASP package.

## 2. Repository Contents

The repository contains the following computational materials and data:

| Directory | Contents |
|---|---|
| `relaxed structure/` | Eight optimized atomic structure files in standard VASP POSCAR format |
| `VASP_Input_Files/` | Representative VASP input files and calculation scripts for different computational tasks |
| `Electronic_Structure/PtSSe-SiC/` | Selected band-gap and projected electronic-structure data for S-side and Se-side interfaces |
| `Optical_Properties/PtSSe-SiC/` | Calculated optical absorption data for S-side and Se-side interfaces |

The optimized atomic structures cover the following heterostructures:

| Heterostructure | Interfacial configurations | Number of structures |
|---|---|---|
| PtS2/SiC | Optimized structure | 1 |
| PtSe2/SiC | Optimized structure | 1 |
| PtSSe/SiC | S-side and Se-side interfaces | 2 |
| WSSe/HfS2 | S-side and Se-side interfaces | 2 |
| WSSe/ZrS2 | S-side and Se-side interfaces | 2 |
| **Total** | | **8** |

## 3. File Formats

The optimized atomic structures are provided in standard VASP POSCAR format. The computational input files include representative INCAR, KPOINTS, and other relevant parameter files. Selected numerical data are provided in their corresponding formats, including DAT files.

The files are organized into folders according to their corresponding heterostructures, interfacial configurations, and computational tasks.

## 4. Data Scope

This repository provides the optimized atomic structures, representative computational input files, and selected numerical data currently available for this study. 
The computational methodology and relevant results are described in the associated manuscript and its Supporting Information.
